# Special Repository #
This repository is a container for a single release containing only
binary assets, which make up a Pacman repository for dependencies
that the MSYS2 project does not support.
Those packages are:

[AqBanking](https://aquamaniac.de/rdm/projects/aqbanking)  GNU GPL Version 2 or 3
[Guile](https://codeberg.org/guile/guile) GNU LGPL Version 3 or later
{Gwenhywfar](https://aquamaniac.de/rdm/projects/gwenhywfar) GNU GPL Version 2 or 3
[Libchipcard](https://aquamaniac.de/rdm/projects/libchipcard) GNU GPL Version 2 or 3
[LibOFX](https://github.com/libofx/libofx) GNU GPL Version 2
[LibDBI](https://sourceforge.net/projects/libdbi/) GNU LGPL Version 2.1
[LibDBI-Drivers](https://sourceforge.net/projects/libdbi-drivers/) GNU LGPL Version 2.1
[SWIG](https://github.com/swig/swig) GNU GPL Version 3 or later

Copies of all three licenses are included in this repository.
